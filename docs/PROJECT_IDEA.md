# فكرة مشروع سكني

**من إنشاء وتنفيذ:** Abdelrahman Atef Fawzy Aly  
**تحت إشراف المشروع:** Taha Mahmoud Metwally Nour El-Dein

أُنجز المشروع ضمن منحة تعليمية من Replit.

## المشكلة

البحث عن سكن مناسب للطلاب قد يتطلب متابعة إعلانات ومحادثات متفرقة. يصعب أحيانًا المقارنة بين الموقع والسعر والمرافق والتوافر، أو معرفة تفاصيل التكلفة قبل إرسال طلب الحجز.

## الفكرة

**سكني** منصة عربية تجمع معلومات السكن الطلابي في مكان واحد. تساعد الطالب على البحث والمقارنة وطلب الحجز، وتمنح مالك السكن أدوات لإدارة إعلاناته، مع لوحة للإدارة لمراجعة المحتوى ومتابعة المستخدمين والطلبات.

يركز نطاق المشروع الحالي على دمياط ودمياط الجديدة ورأس البر، مع إمكانية التوسع مستقبلًا إلى محافظات أخرى.

## الفئات المستفيدة

1. **الطالب:** يبحث حسب احتياجاته، ويحفظ الإعلانات، ويقارن الخيارات، ويرسل طلبات الحجز ويتابعها.
2. **مالك السكن:** يدير الإعلانات والوحدات والأسعار ويستقبل طلبات الحجز ويتابعها.
3. **مشرف المنصة:** يراجع الإعلانات وطلبات التوثيق، ويدير المستخدمين والإعدادات والدعم.

## أهم خصائص المشروع

- البحث حسب المدينة والجامعة ونوع السكن والميزانية والمرافق والتواريخ.
- عرض تفاصيل السكن والتوافر والمقارنة بين خيارات متعددة.
- إظهار تفاصيل التكلفة المرتبطة بطلب الحجز.
- شارة توثيق ترتبط بموافقة الإدارة بعد المراجعة.
- المفضلة والرسائل والإشعارات والدعم والبلاغات.
- مطابقة شركاء السكن مع حماية بيانات التواصل قبل القبول.
- واجهة عربية متجاوبة مع الهاتف والحاسوب.

## التقنيات

بُني التطبيق باستخدام **Next.js وReact وTypeScript**، مع **PostgreSQL وDrizzle ORM** لإدارة البيانات.

## المرحلة الحالية

يقدّم المشروع وظائف للبحث وإدارة الإعلانات وطلبات الحجز. الدفع الإلكتروني الفعلي ورسائل SMS والبريد الخارجي وتخزين المستندات غير مفعّلة حاليًا، وتحتاج إلى تكاملات وسياسات تشغيل قبل الاعتماد عليها.
